# 人设加载（0.8.3）

## 源文件与更新

默认源文件是 `$DSH_HOME/pod-persona.md`，可用 `BILI_POD_PERSONA` 覆盖。首次启动时，如果新位置不存在，会复制旧 `~/.bili-ai/persona.md`，保留原件。之后编辑新源文件或在设置页保存即可；不会持续用旧文件覆盖新文件。

保存上限为 20000 字符（JavaScript UTF-16 长度）。超限明确拒绝，不再截取前 3000 字。直接编辑造成的超限会在下一次投递时报告，设置页仍可读出全文供修改。字符数不是 token 数。

每次唤醒或消息投递前重新读取文件。支持 `agent/pre-step` 的 DSH 还会在小鲸鱼会话的每个模型步骤前同步原生投影，覆盖直接在 DSH 中对她发消息的情况；不会改其他会话。普通人设编辑不需要重启应用。新代码首次装入运行进程仍需要插件重载，或经用户同意的应用重启。

## 两种模式

`persona.loadMode=inline` 是兼容默认值：完整正文随本轮任务消息注入。适用于不支持原生工作区指令的 DSH，正文会在会话历史中重复出现。

`persona.loadMode=workspace` 用于支持 `@deepseek-ai/dsh-agent-instructions` 的 DSH：

1. 正文同步到小鲸鱼工作目录 `AGENTS.md` 的 `dsh-bili-pod:persona:start/end` 标记区。
2. 原有非鲸群内容保留；标记不完整时报告错误，不覆盖原文件。
3. DSH 原生指令投影负责基线、版本变更及上下文恢复。鲸群的每轮任务只带版本引用、相关示例与记忆入口，避免每轮向用户消息追加全文。
4. 当前 DSH 安装的默认工作区指令预算为 65536 字节。生成的 AGENTS.md 超过该预算会被拒绝。全局及祖先目录的指令也共享 DSH 的预算，使用前应检查实际配置及总量，不能把这个本地检查理解为对所有 DSH 配置的保证。
5. 会话 cwd 与小鲸鱼工作目录实际不是同一目录时，记录警告并回退 inline，避免把人设写进其他项目。C/F 目录联接按实际目录比较。

切换回 inline 或清空人设时，移除鲸群投影标记区，其余 AGENTS.md 内容保留。工作区模式只应用在该工作目录；普通项目会话不会读取这份文件。

固定人设仍会占用模型输入上下文；减少历史中的重复追加，不代表后续请求不计这部分输入，也不保证命中提供商缓存。

## 场景例子与日记

`## 不同场景的语气参考` 下的 `###` 小节作为例子，其他正文完整保留。章节前言保留在固定正文中。如果没有这种结构，则全文作为正文，不猜测切分位置。

根据唤醒来源与当前私信关键词选择最多两个相关例子；没有明确匹配可不附加。例子标明仅参考语气，里面的事件不成为实际记忆。

共同记忆优先来自已有近期对话。过去经历继续按需查日记和分类索引，不自动灌入所有日记，也不在每次消息前新增一次模型总结。旧口音本中的过时要求不能覆盖当前人设。

## 设置与存档

设置页显示源文件位置、版本、加载模式和字数。完整正文中的身份表达优先；基本身份配置只补充未另作设定的部分。

源文件、设置页、调度器及存档使用同一套路径。存档包仍保存 `home/persona.md`，可以读旧包；导出会兼容尚未迁移的旧人设文件，导入写入当前目标路径。私人人设和生成的工作区文件不要提交到公开源码仓库。

## 部署核验范围

本次使用静态语法检查、差异检查及本机文件/运行状态核对。没有运行自动测试套件，也没有发送真实模型请求、B 站私信或评论来验证效果。实际回复效果需要在正常使用中确认。

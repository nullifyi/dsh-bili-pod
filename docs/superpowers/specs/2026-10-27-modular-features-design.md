# 鲸群可配置功能模块设计

用户已要求直接实施。沿用现有 PodHost，不新建插件框架。共享内核继续负责会话、身份、权限、发送、调度与数据；可选功能以独立 mod 包注册设置、路由与展示面板。模块不是进程沙箱，也不拥有发送权限的旁路。

## 模块边界

新增 extensions/<id>/mod.json + index.mjs。静态 manifest 给出 id/name/version/apiVersion/main/fields/panels。放入目录即被发现；配置禁用时只读 manifest，不 import 入口；legacy .mjs/API v1 保持兼容。API v2 新增数据面板声明、类型化字段（多选、带标签下拉、长文本、数字约束）。配置保留在现有路径，关模块不删值。

PodHost 管注册、启停、错误、单模块重载及回收；设置层只渲染声明，不按模块名写分支。重载一个模块不得重启其他模块，失效/失败实例不保留回调或路由。动态字段请求始终走原信任栅栏。

## 本次功能包

favorite-picker：用登录账号读取自己的收藏夹，渲染标签化下拉；失败显示错误、保留原ID，关闭后退回原ID输入。复用只读API及流量保护，不执行收藏。

watched-library：从实际本地记录生成看过的视频列表，支持搜索/过滤；只读、不把推荐候选当已看，不默认联网抓封面。

sharing-controls：将公开/私信投递、允许自动发送对象的控件做成模块声明，用多选替代手填数组；沿用现有配置和发送规则，不自动开启发送。

public-comment-style：迁移既有公开评论语气，按wake/listen注入，提供自然/简短/交流选项，不影响DM身份。

设置页按日常、人设与记忆、交流与审核、功能mod、高级分Tab；模块卡片里显示所属设置、展示面板、状态、单独重载，开关后同步表单。未保存编辑跨Tab保留；重载/切换前有未保存编辑则阻止并提示先保存或撤销。

## 验收

新建第三方fixture包仅添加文件即可出现控件/面板；禁用入口不执行；类型与路径校验失败不写配置；单独重载只回收该模块；legacy测试通过。离线fixture检验收藏夹归属与数据输出、历史过滤。实际DSH设置页验证Tab/多选/下拉/卡片与启停；无实际对外发送。部署前保存SHA并核对主仓库无他人改动，不改人设与日记。
